# Minimum Working Council

Цель минимально работающего совета: пользователь одной командой создает настоящее философское заседание, где несколько независимых машин-личностей дают отдельные позиции, а затем `Agora Assistant / Синтезатор` собирает итог.

## MVP-состав

Минимальный совет состоит из трех архитекторов:

- Платон — проверяет вопрос через истину, форму и восхождение от мнения к сущности.
- Декарт — проверяет вопрос через метод, сомнение, ясность и основание.
- Хайдеггер — проверяет вопрос через бытие, язык, подлинность и техническое мышление.

Этот состав выбран как минимальный, потому что он уже дает три разные рамки:

- вертикаль истины;
- методическое основание;
- онтологическую глубину.

## Что считается рабочим

Минимальный совет работает, если:

1. Команда принимает вопрос пользователя.
2. Создается root issue в Paperclip.
3. Создаются ровно три child issue: Платон, Декарт, Хайдеггер.
4. Каждый философ получает отдельную задачу и отвечает сам за себя.
5. После ответов можно создать задачу синтеза для `Agora Assistant / Синтезатор`.
6. Синтез явно собирает позиции, конфликты, скрытые предпосылки и следующий шаг.

## Команда

```bash
node scripts/agora.mjs council "Что такое свобода?"
```

Проверить без создания задач:

```bash
node scripts/agora.mjs council --dry-run "Что такое свобода?"
```

После завершения философских задач:

```bash
node scripts/agora.mjs synthesize THE-1
```

`THE-1` нужно заменить на root issue из вывода команды `council`.

## Hermes

Через Hermes gateway:

```text
/agora-council QUESTION
```

## Не входит в MVP

- Полный пантеон философов.
- Автоматическое ожидание всех ответов.
- Автоматический синтез без команды пользователя.
- Глубокие историко-филологические профили.
- Telegram-настройка профиля `inneragora`.

Эти вещи можно добавить позже. Сейчас цель — надежный минимальный цикл: вопрос -> 3 независимых голоса -> синтез.
