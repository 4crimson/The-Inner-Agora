# The Inner Agora

The Inner Agora — это набор философских машин-личностей для исследования, диалога и спора.

Проект не должен быть "советом директоров в философских костюмах". Его задача — собрать пространство, где разные философские умы могут быть вызваны как самостоятельные интеллектуальные присутствия: со своей картиной мира, языком, темпераментом, убеждениями, конфликтами и слепыми зонами.

## Базовая идея

Пользователь приносит вопрос, текст, идею, дилемму или исследовательскую тему.

Agora:

1. Понимает, какой тип разговора нужен.
2. Вызывает релевантных философов.
3. Дает им спорить не как функциям, а как мировоззрениям.
4. Сохраняет конфликт позиций.
5. Собирает итог через ассистента-синтезатора.

Ценность системы не в одном правильном ответе, а в многоголосом мышлении.

## Главные слои

| Слой | Назначение | Что в нем живет |
|------|------------|-----------------|
| Agora Assistant | Секретарь, модератор и синтезатор | сбор вопроса, выбор участников, итоговая карта |
| Architect Layer | Верхняя рамка мышления | Платон, Декарт, Хайдеггер |
| Philosopher Layer | Машины-личности философов | отдельные интеллектуальные присутствия |
| Session Layer | Конкретные заседания | вопрос, реплики, спор, синтез |
| Memory Layer | Долгая память | выводы, нерешенные вопросы, карты идей |
| Research Layer | Работа с текстами и источниками | заметки, цитаты, реконструкции позиций |

## Архитекторы

Архитекторы не являются начальниками. Они задают три больших режима сборки разговора.

### Платон

Держит вертикаль истины, формы и восхождения от мнения к сущности.

### Декарт

Держит метод, ясность, сомнение, основание и проблему субъекта.

### Хайдеггер

Держит вопрос о бытии, языке, подлинности, заброшенности и техническом мышлении.

## Что такое философская машина

Философская машина — это не узкая роль и не "ответственный за тему".

Например:

- Сократ не просто "задает вопросы"; он разрушает ложную уверенность.
- Кант не просто "про мораль"; он требует формы, закона и достоинства разума.
- Фуко не просто "про власть"; он подозревает, что истина уже произведена режимами знания.
- Хайдеггер не просто "про смысл"; он возвращает разговор к забытому вопросу о бытии.

Каждая машина позже должна получить профиль:

- центральная интуиция;
- картина реальности;
- понимание истины;
- понимание человека;
- этический нерв;
- враги мышления;
- стиль речи;
- слепая зона;
- поведение в споре.

## Типы сессий

| Режим | Когда использовать | Результат |
|-------|--------------------|-----------|
| Dialogue | Хочется поговорить с одним философом | живой диалог с личностью |
| Council | Нужен спор нескольких перспектив | карта позиций и синтез |
| Research | Нужно разобрать тему или текст | исследовательская записка |
| Trial | Нужно подвергнуть идею жесткой критике | обвинение, защита, вердикт |
| Meditation | Нужен медленный экзистенциальный разбор | прояснение внутреннего вопроса |
| Genealogy | Нужно понять происхождение идеи | историко-дискурсивная карта |

## Минимальный поток работы

1. Пользователь формулирует вопрос.
2. Agora Assistant уточняет тип сессии.
3. Assistant выбирает 1, 3, 5 или 7 философов.
4. Философы дают позиции.
5. Философы могут спорить друг с другом.
6. Assistant собирает:
   - главные линии согласия;
   - главные линии конфликта;
   - скрытые предпосылки;
   - сильнейшие аргументы;
   - нерешенные вопросы;
   - практический или исследовательский итог.

## Принцип сложности

Проект нужно развивать слоями:

1. Сначала схема и состав.
2. Потом простые профили философов.
3. Потом протоколы сессий.
4. Потом память и журнал диалогов.
5. Потом исследовательский режим с источниками.
6. Потом технический запуск через локальные агенты, Paperclip, Hermes или другой рантайм.

Промпты и точные системные инструкции появятся позже. Сейчас важнее не потерять архитектуру и идею.

## Локальный запуск

### 1. Подготовить Hermes-профиль

```bash
node scripts/setup-hermes-profile.mjs
```

Это создаст профиль `inneragora`, установит Hermes plugin `inner-agora-commands` и добавит команду:

```bash
inneragora status
```

Секреты Telegram не копируются автоматически из других профилей.

### 2. Проверить Paperclip

```bash
curl http://127.0.0.1:3100/api/health
```

Если Paperclip не запущен:

```bash
launchctl kickstart -k gui/$(id -u)/local.paperclipai.default
```

### 3. Импортировать Агору в Paperclip

```bash
node scripts/import-inner-agora.mjs
```

Или через bridge:

```bash
node scripts/agora.mjs prepare
```

### 4. Создать сессию

```bash
node scripts/agora.mjs ask "Что такое подлинность в эпоху алгоритмов?"
node scripts/agora.mjs ask --philosophers socrates,kant,foucault "Что такое свобода?"
node scripts/agora.mjs dialogue heidegger "Что значит мыслить технически?"
```

После ответов философов:

```bash
node scripts/agora.mjs synthesize ISSUE
```

### Hermes slash-команды

```text
/agora-prepare
/agora-status
/agora-tasks
/agora-ask [--min|--balanced|--max|--all|--philosophers list] QUESTION
/agora-dialogue PHILOSOPHER QUESTION
/agora-synth ISSUE
/agora-memory ISSUE
/agora-guard
```
