# Web Research

Use this skill only when the chamber and role explicitly allow `web-research`.

<!-- INNER_AGORA_SKILL_PROMPT_START -->
Скилл `web-research` разрешает только чтение внешних источников: поиск, открытие страниц и проверку фактов.

Правила:
- Используй web-поиск, когда вопрос зависит от свежих фактов, конкретных источников, дат, цен, людей, компаний, законов, версий библиотек или текущих событий.
- Не утверждай, что исследование выполнено, если web-инструмент не запускался или вернул ошибку.
- Отделяй найденный источник от собственной интерпретации.
- Не выполняй действия записи во внешних системах.
- Для итогов сохраняй краткие ссылки/названия источников и дату проверки.
